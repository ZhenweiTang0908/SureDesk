# Frontend skills

These skills are vendored from Anthropic's public [skills repository](https://github.com/anthropics/skills) at commit 2c5958e:

- **frontend-design** — visual direction, typography, and layout guidance for new or reshaped interfaces.
- **webapp-testing** — Playwright-based browser verification and screenshot capture.
- **web-artifacts-builder** — building interactive web artifacts.
- **theme-factory** — reusable visual themes for generated artifacts.

Each skill keeps its original LICENSE.txt (Apache License 2.0). The SureDesk UI was designed and verified with frontend-design and webapp-testing; see docs/screenshots/ for the rendered result and scripts/capture_ui.py for the capture workflow.
